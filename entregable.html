Nuestras Carreras

1. Ciberseguridad

Protege los sistemas, redes y datos de las empresas contra ataques informáticos.

2. Ciencia de Datos e IA

Analiza grandes cantidades de datos y crea modelos inteligentes para tomar decisiones.

3. Desarrollo de Software

Diseña, crea y mantiene programas, aplicaciones móviles y sistemas.

4. Diseño UX/UI

Mejora la experiencia del usuario y diseña la interfaz visual de páginas web y apps.

5. Ingeniería Robótica

Mezcla mecánica, electrónica y programación para construir robots.

6. Cloud Computing

Administra y organiza los servicios y datos en la nube virtual.

7. Desarrollo Web

Crea y programa sitios de internet funcionales y atractivos.
