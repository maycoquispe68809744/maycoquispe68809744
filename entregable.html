Nuestras Carreras

1. Ciberseguridad

Protege los sistemas, redes y datos de las empresas contra ataques informáticos y robos de información.

2. Ciencia de Datos e Inteligencia Artificial

Analiza grandes cantidades de datos y crea modelos inteligentes para mejorar la toma de decisiones.

3. Desarrollo de Software

Diseña, crea y mantiene programas, aplicaciones móviles y sistemas para computadoras.

4. Diseño UX/UI

Mejora la experiencia del usuario y diseña la interfaz visual de páginas web y aplicaciones móviles.

5. Ingeniería Robótica

Mezcla la mecánica, la electrónica y la programación para construir robots y automatizar procesos.

6. Cloud Computing

Administra y organiza los servicios y datos que se encuentran guardados en la nube virtual.

7. Desarrollo Web

Crea y programa sitios de internet funcionales y atractivos para el público.
